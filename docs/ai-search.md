# Public search and AI reference maintenance

Bricks uses the same public facts for readers, structured data and AI text exports. These files improve clarity and access; they do not guarantee indexing, rankings, rich results or citations.

## Sources of truth

- `src/lib/public-content.ts`: software-first definition and the home, listing-media and Site Progress answers. The answers are rendered on their pages and used in FAQPage JSON-LD.
- `src/lib/catalog.ts`: published software plan labels and prices. Structured offers derive their numeric CAD amounts from this catalog; never add ratings, reviews or discounts to satisfy a rich-result checker.
- `src/lib/schema.ts`: Organization, WebSite, SoftwareApplication, Service and breadcrumb definitions. The root layout emits the shared organization and website once per page. All providers and publishers reference that organization.
- `public/llms.txt`: short source index. Keep links and positioning accurate; do not turn it into an unmaintained second price catalog.
- `/llms-full.txt`: generated by `src/lib/llms.ts` from the shared definitions, catalog, enabled service trades and the complete public help article data. No private application data is included.
- `src/app/sitemap.ts`: canonical marketing, booking and help routes. Update the stable content date after a meaningful site-wide content change, not on every build. Help articles retain their authored update dates. Customer project data, API endpoints, gated controls and noindex demos are not enumerated.

## Access and validation

`robots.txt` explicitly allows search/retrieval crawlers and the training-control agents requested by the owner, while retaining the wildcard allow rule. GPTBot, Google-Extended and Applebot-Extended are not prerequisites for appearing in AI search. Robots permissions do not bypass authentication, WAF rules or rate limits. Verify actual crawler access in hosting logs using the providers' current verified IP guidance; never trust a User-Agent alone for a security bypass.

Both AI text endpoints remain allowlisted if the existing marketing gate is enabled, but the gate still protects other non-public pages. No authentication or hosting-security setting is weakened.

Run `npm test`, `npm run typecheck` and `npm run build` before release. Check HTTP responses for the text endpoints and sitemap; extract and parse JSON-LD from raw HTML. Verify CAD offers, real FAQ answers, source links, breadcrumbs, one H1 and no skipped heading levels. Check the home, pricing and booking flows after deployment. Schema vocabulary/shape validation is not an endorsement by Google or any other search engine.

## Off-site follow-up

Confirm ownership and sitemap submission in Google Search Console and Bing Webmaster Tools; request inspection of important pages. Keep the existing Google Business Profile and linked social profiles accurate, without creating duplicate listings. Build genuine independent mentions, links and customer reviews only with permission and evidence. Do not manufacture third-party endorsements or promise placement in AI answers.
