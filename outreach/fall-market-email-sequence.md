# Fall Market Email Sequence

Companion copy for `fall-market.html`. **Not a send list or a campaign — a set of ready templates.**

## Who this can actually go to

As of 2026-08-14, `newsletter_subscribers` has **zero rows** — no one has opted in yet, so there
is no "agents who've been on the fence" list to send this to. CASL requires opt-in consent for
commercial email; per `linkedin-outreach.md` this project already runs outreach 1:1, no blast.

Two real ways to use this:
1. **Newsletter nurture** — once someone submits the `fall-market.html` form (source: `fall-market`),
   they've opted in. These three emails are what they'd receive, spaced a few days apart, run through
   whatever ESP gets wired up to `newsletter_subscribers` (nothing sends automatically today — the
   table only stores signups).
2. **1:1 outreach copy** — pull individual lines into direct emails/DMs the way `linkedin-outreach.md`
   angles are used, not sent verbatim to a list.

Do not connect this to a bulk sender against a purchased or scraped list. If a real opted-in list
exists somewhere else (CRM, past bookings with consent, etc.), confirm consent basis before using it.
