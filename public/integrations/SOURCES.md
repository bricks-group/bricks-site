# Integration logos — sources & usage rules

Used by `src/lib/integrations.ts` (shared list) → `src/components/calm/Integrations.tsx` (home `#integrations` row, platform `#integrations` list), and the legacy `src/components/IntegrationsBand.tsx`.

**Calm concept (2026-10-24): uniform grey, Kam's decision.** On 2026-10-24 Kam decided every integration logo (Stripe, Repliers, PropTx, Bridge Interactive) renders as one uniform single-tone grey silhouette (light grey in dark mode), explicitly accepting the risk that this departs from vendor brand guidelines (Repliers: no recolouring; Stripe: slate/blurple/white only; PropTx: do not alter marks). Source files stay official and unaltered; the grey is a CSS filter at render time. Stripe's source is the official Slate wordmark (row below); `stripe-white.svg` is kept in the repo but not used. Follow Up Boss and kvCORE / BoldTrail stay plain text names (no logo permission) in the exact same grey. kvCORE / BoldTrail is on the full platform list but not the homepage row. Google Calendar, Apple Calendar and Google sign-in are not listed (Kam, 2026-10-24). Follow Up Boss is described as "Contact sync" only: two-way sync is not built yet (Kam, 2026-10-24).
Collected 2026-10-11. Files are byte-identical vendor downloads, except large PNGs
were scaled down **proportionally** (no crop, recolour, or distortion).
On the page every logo sits on a fixed light plate (#F4F1EB) in light **and** dark mode,
so full-colour versions are never shown on a dark background.

Page fine print: "Logos are trademarks of their respective owners. No endorsement implied."
Copy uses "Works with" / "Connects to" only. Never "partner", "certified", or "official".
